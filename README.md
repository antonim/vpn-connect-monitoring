# VPN Connect Monitoring

Следит за тем, что VPN-подключение поднято в рабочее время, предупреждает
уведомлением со звуком, когда связь отваливается, и ведёт журнал — чтобы
потом увидеть на графике, в какой момент это произошло.

Значок в трее или в строке меню, никаких серверов и учётных записей:
всё работает локально.

## Скачать

| Система | Файл | Требования |
|---|---|---|
| Windows 10 / 11 | **[VpnConnectMonitoring.exe](https://github.com/antonim/vpn-connect-monitoring/releases/latest)** | нет, .NET Framework 4.8 уже в системе |
| Ubuntu / Debian | **[vpn-connect-monitoring_*.deb](https://github.com/antonim/vpn-connect-monitoring/releases/latest)** | `sudo apt install ./файл.deb` |
| macOS | **[vpn-connect-monitoring-*-macos.tar.gz](https://github.com/antonim/vpn-connect-monitoring/releases/latest)** | распаковать, `./install.sh` |

Права администратора не нужны ни в одной из систем: настройки
и автозапуск пишутся в профиль пользователя.

## Что умеет

- Опрос VPN по расписанию: рабочие часы, дни недели, интервал 10–3600 секунд.
- Уведомление при обрыве со своим звуком — нисходящий мотив, не похожий на
  системные звуки. При восстановлении связи — короткий восходящий.
- Журнал состояния и график: когда именно пропадала связь, доступность
  в процентах, таблица обрывов с длительностью.
- Настройка частоты повторных предупреждений, пауза на час, переключатель
  звука прямо в меню значка.
- Список доступных VPN-подключений приложение собирает само — искать имена
  вручную не нужно.

## Устройство

Linux и macOS делят один код на Python: различаются только адаптеры —
определение VPN, уведомления, звук, автозапуск и значок. Windows-версия
отдельная, на C# с WinForms и WinRT.

Совпадают у всех трёх формат конфига и журнала, логика расписания и правила
построения графика.

| | Windows | Linux | macOS |
|---|---|---|---|
| Язык | C# 5, WinForms | Python 3, GTK 3 | Python 3, PyObjC |
| Сборка | `csc.exe` из состава Windows | `dpkg-deb` | `tar` |
| Результат | exe, 86 КБ | deb, 20 КБ | tar.gz, 28 КБ |
| Зависимости у пользователя | нет | python3, libnotify-bin | python3 из Command Line Tools |

Все три сборки намеренно обходятся тем, что уже есть в системе: ни .NET SDK,
ни виртуальных окружений, ни сторонних библиотек не требуется.
